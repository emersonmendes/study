# Projeto Study

Este repositório contém um conjunto de exemplos utilizados para estudos de Java e Spring Boot. Aqui você encontrará implementações de algoritmos, estruturas de dados e padrões de projeto.

## Requisitos

- Java 21
- Maven (pode ser utilizado o *wrapper* incluído no projeto)

## Execução da aplicação

Para iniciar a aplicação utilize o comando:

```bash
./mvnw spring-boot:run
```

Após a inicialização, acesse `http://localhost:8080/` para verificar a mensagem "Welcome :)".

## Testes

Os testes unitários podem ser executados com:

```bash
./mvnw test
```

## Estrutura

O código-fonte principal encontra-se em `src/main/java` e os testes em `src/test/java`. O projeto está organizado em pacotes que demonstram diferentes técnicas como algoritmos, padrões de projeto, estruturação de dados e exemplos de uso do Spring.
